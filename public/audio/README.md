# Audio Assets

Place all audio files here.

## Expected Files

| File | Purpose |
|---|---|
| `background.mp3` | Ambient background music |
| `transition.mp3` | Scene transition sound effect |
| `gift_open.mp3` | Gift opening sound |
| `magic_chime.mp3` | Magical chime sound |
| `butterflies.mp3` | Butterflies release sound |
| `celebration.mp3` | Celebration / fireworks sound |

## Usage

All audio paths are managed centrally in `src/config/audio.ts`.
To replace audio, upload a new file with the same name.
No code changes are required.
